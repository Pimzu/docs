### Get Outfit

Gets an outfit from the Pedsense outfit library.

**By Name:**

```lua
local outfit, name, tag, key = exports["pedsense"]:getoutfit({
	Gender = "male",
	
	Name = "Security"

})
```

**By Tag:**

```lua
local outfit, name, tag, key = exports["pedsense"]:getoutfit({
	Gender = "male",
	Tag = "Police"

})
```

**Returns:**

- `outfit` — Clothing data.<br />
- `name` — Saved outfit name.<br />
- `tag` — Outfit tag.<br />
- `key` — Outfit key.<br />

---

### Wear Outfit

Gets an outfit from Pedsense and immediately applies it to a ped.

```lua
local success = exports["pedsense"]:wearoutfit({
	Ped = ped,
	
	Gender = "male",
	
	Name = "Security"

})
```

**Returns:**

- `success` — `true` when the outfit was successfully applied.<br />

---

### Set Outfit

Sets a Pedsense outfit on a ped.

```lua
local ped, gender = exports["pedsense"]:setoutfit({
	Ped = ped,
	
	Gender = "male",
	
	Outfit = "Security"

})
```

A tag can also be supplied:

```lua
local ped, gender = exports["pedsense"]:setoutfit({
	Ped = ped,
	
	Gender = "male",
	
	Outfit = "Security",
	
	Tag = "Police"

})
```
