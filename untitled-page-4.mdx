Use these exports from a **client-side Lua file**.

Spawn Ped

Spawns a ped using Pedsense and returns the created ped entity and processed ped data.

```lua
local ped, data = exports["pedsense"]:spawn({

    ------------------------------------------------------------------
    -- PED APPEARANCE
    ------------------------------------------------------------------

    -- OPTION 1: Use a normal GTA ped model.
    -- Use this if you just want to spawn a ped model without
    -- using a saved Pedsense Outfit or Face.
    Model = "a_m_m_business_01",

    -- OR

    -- OPTION 2: Use an Outfit and/or Face saved inside Pedsense.

    -- Name of the saved Pedsense Outfit you want to use.
    Outfit = "Shop Keeper",

    -- Name of the saved Pedsense Face you want to use.
    Face = "Shop Keeper",

    -- Gender used when loading the Outfit / Face.
    -- Use "male" or "female".
    Gender = "male",


    ------------------------------------------------------------------
    -- LOCATION
    ------------------------------------------------------------------

    -- Where the ped will spawn.
    -- vector4(X, Y, Z, Heading)
    --
    -- X / Y / Z = World position
    -- Heading   = Direction the ped will face
    Coords = vector4(
        24.47,      -- X
        -1346.62,   -- Y
        29.50,      -- Z
        271.0       -- Heading
    ),


    ------------------------------------------------------------------
    -- SYNC
    ------------------------------------------------------------------

    -- Controls whether the ped is networked.
    --
    -- true  = Ped is networked/synchronized between players.
    -- false = Ped only exists locally for this client.
    --
    -- Use true when other players need to see/interact with the
    -- same networked ped.
    Sync = true,


    ------------------------------------------------------------------
    -- 3D TEXT
    ------------------------------------------------------------------

    -- OPTIONAL
    -- Displays 3D text above the spawned ped.
    Text = {

        -- Text displayed above the ped.
        Message = "Shop Keeper",

        -- Hex color of the text.
        Color = "#FFFFFF",

        -- GTA/FiveM font ID.
        Font = 0,

        -- Size of the text.
        Size = 0.35,

        -- Vertical position of the text above the ped.
        Top = 1.0
    },


    ------------------------------------------------------------------
    -- MAP BLIP
    ------------------------------------------------------------------

    -- OPTIONAL
    -- Creates a map blip attached to the spawned ped.
    Blip = {

        -- Name displayed for the blip.
        Title = "Shop",

        -- GTA/FiveM blip sprite ID.
        Sprite = 52,

        -- GTA/FiveM blip color ID.
        Color = 2,

        -- Size of the blip.
        Scale = 0.8
    },


    ------------------------------------------------------------------
    -- PED FLAGS
    ------------------------------------------------------------------

    -- OPTIONAL
    -- Controls the behavior/properties of the spawned ped.
    Flags = {

        -- true  = Ped stays in its current position.
        -- false = Ped is allowed to move.
        Freeze = true,

        -- true  = Ped cannot take damage or die.
        -- false = Ped can take damage normally.
        Invincible = true,

        -- true  = Ped can react/become alert.
        -- false = Prevent normal alert reactions.
        Alert = false,

        -- true  = Normal collision is enabled.
        -- false = Players/entities can pass through the ped.
        Collision = true
    }
})
```

**Returns:**

- `ped` — The spawned ped entity.
- `data` — The processed Pedsense ped data.

Route

Starts a saved Pedsense route on a ped.

```lua
exports["pedsense"]:Route(ped, routeName, function(data)
        -- data.Index tells you which route step is currently being
        -- triggered.
        --
        -- You can check the Index to make different route steps
        -- perform different actions.


        -- ROUTE STEP 1
        if data.Index == 1 then

            print("Ped reached route step 1")

            -- Put any custom code you want here.
            --
            -- Example:
            -- TriggerEvent("myresource:firstStep")

        end


        -- ROUTE STEP 2
        if data.Index == 2 then

            print("Ped reached route step 2")

            -- Example custom code:
            -- TriggerServerEvent("myresource:secondStep")

        end


        -- ROUTE STEP 3
        if data.Index == 3 then

            print("Ped reached route step 3")

            -- You can access the ped here as well.
            TaskTurnPedToFaceEntity(
                ped,
                PlayerPedId(),
                1000
            )

        end


        ------------------------------------------------------------------
        -- VIEW ALL CALLBACK DATA
        ------------------------------------------------------------------

        -- Useful while developing to see everything Pedsense
        -- returned for the current route step.
        print(json.encode(data))

    end, deletePedOnStop
)
```

**Parameters:**

- `ped` — Ped entity or Pedsense ped entry.
- `routeName` — Name or key of the saved route.
- `onStep` — Optional callback triggered during the route.
- `deletePedOnStop` — Whether the ped should be deleted when the route stops.

**Example:**

```lua
local ped = exports["pedsense"]:spawn({
    Model = "a_m_m_business_01",
    Coords = vector4(215.76, -810.12, 30.73, 157.0),
    Sync = true
})

exports["pedsense"]:Route(ped, "Walk To Store")
```
