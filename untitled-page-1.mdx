How to add voices to pedsense

## Adding New Voices

1. Navigate to html/voices and decide the gender of the voice you are adding
2. Open the FEMALE or MALE folder
3. Create a NEW folder and name it THAT NAME WILL BE THE VOICE ID
4. Put all Audio files for that voice in that folder
5. Restart PedSense

<Tip>
  Try to name each Voice Id and  audio file something short so you can add it in the menu easier
</Tip>

1. Open PedSense in Fivem and Navigate to the Voices Tab
2. Click Add Voice button at the top right
3. Select the Gender of the voice you want to add
4. Put the Voice Id exactly how it is named in the folder
5. Add all the audio files 1 by 1 and click Test to hear playback
