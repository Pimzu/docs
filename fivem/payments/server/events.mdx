---
title: "Server Events"
---

Create a REAL Payment

```lua
TriggerEvent('payments:server:Charge', playerID, {
    amount = 23,
    description = 'Test Description'
})
```

---

Create a FAKE Payment

```lua
TriggerEvent('payments:server:Fake', playerID, {
    amount = 23,
    description = 'Test Description'
})
```
